# Progress So Far — Navier–Stokes Physical Approximation Project

This file summarizes the project through the **sixth milestone** so a new AI
conversation can resume without reconstructing the full prior chat.

Repository:

```text
rharriszzz/navier-stokes-physical-approximation
```

Main scientific goal:

> Investigate whether some finite, physically meaningful approximation to the
> mechanism in OpenAI's 2026 finite-time Navier–Stokes blowup construction can
> be simulated or ultimately related to a realizable fluid experiment.

This is **not** an attempt to re-prove the theorem numerically.

The project explicitly distinguishes:

1. theorem-admissible proof parameters;
2. relaxed finite mathematical models;
3. numerically converged local-core models;
4. globally matched/stress-compatible models;
5. dynamically simulated flows;
6. physically realizable laboratory approximations.

We are currently between levels 2 and 3.

---

# 1. Core comparison: validated but prescribed

The first milestone implemented the explicit Appendix-B comparison field.

Validated:

- similarity coordinate maps;
- physical velocity reconstruction;
- analytical incompressibility;
- second-order divergence convergence;
- rescaled-profile collapse;
- expected prescribed similarity scaling.

Important limitation:

The observed shrinking core and growing velocity are consequences of the
prescribed similarity formulas.

They are **not** dynamically generated by a Navier–Stokes time integration.

The explicit comparison is therefore a reference profile, not yet a solved
nonlinear core.

---

# 2. Literal proof hierarchy is extremely large

A source audit found that Appendix A imposes constraints including

```text
T_d = exp(M_d) + 10
P_star > exp(T_d)
h < exp(-T_d)
```

so necessarily

```text
h < exp(-10) ~ 4.54e-5
P_star > exp(10) ~ 2.20e4
```

even before the stronger "sufficiently small/large" hierarchy is applied.

The exploratory finite values originally used, such as

```text
h = 0.005
Lambda = 32
sigma = 0.2
```

are therefore not theorem-admissible.

This was treated as a feature of the proof architecture, not a reason to stop.

The project deliberately shifted to **relaxed finite models** in order to ask
whether the underlying mechanism has a useful finite analogue.

# 3. Full scheduled pressure datum implemented

The third milestone implemented the Appendix-A scheduled pressure datum

\[
\Pi_0(\eta)
=
-\frac12\int E_{\mathrm{id,sched}}(y,\eta)^2\,dy
\]

including:

- both infinite ends;
- all finite schedule stages;
- first and second eta derivatives;
- Q stopping construction;
- `Z_star`;
- first explicit Appendix-B axial correction.

The pressure-preserving angular bumps were correctly omitted from the pressure
integral where the paper permits this.

Baseline relaxed parameters were approximately:

```text
M_d = 1
P_star = 2
lambda = 0.2
h = 0.005
j0 = 0.025
T_f = 64
c_o = 0.025
```

Baseline pressure result:

```text
Pi0(0) ~ -13.25849
```

Using only the inner contribution would incorrectly give approximately `-10`.

The pressure and derivative calculations passed:

- quadrature refinement;
- symmetry/sign checks;
- finite-difference derivative convergence;
- stage-join validation;
- Q endpoint checks.

# 4. Proof geometry is enormous

The full relaxed Appendix-A-style schedule spans roughly:

```text
Delta y ~ 324.409
X scale separation ~ 140.889 decades
radius scale separation ~ 70.445 decades
```

This is not a computational-grid requirement because the code uses logarithmic
coordinates, but it is incompatible with any literal laboratory realization.

A large fraction of the span comes from late schedule stages used for:

- pulse support;
- moment corrections;
- angular corrections;
- stress estimates;
- reserved higher-order correction regions.

Many of these late stages contribute essentially nothing to the local pressure
datum because the swirl amplitude has already become extremely small.

---

# 5. Schedule compression experiment

The fourth milestone shortened selected long Appendix-A intervals while keeping
the formulas and pressure construction explicit.

Three combined finite models were studied:

```text
principal_support  ~ 32.45 radius decades
local_slope        ~ 19.20 radius decades
aggressive          ~ 8.78 radius decades
```

The aggressive case sacrifices:

- principal pulse/angular supports;
- the A.10 interpolation-slope bound;
- published suppression estimates;
- reserved correction intervals.

It therefore does **not** represent a globally completed exterior.

However, a striking result emerged:

The aggressive schedule changes

```text
Pi0
Pi0_eta
Pi0_etaeta
Z_star
```

by only about `1e-11` relative to the 70-decade relaxed schedule.

Thus the enormous late radial geometry is almost decoupled from the local
axis pressure datum in this finite experiment.

This does **not** prove that the omitted global moment/stress machinery is
unnecessary.

It does show that the local inner-core forcing is controlled mainly by the
early schedule.

# 7. First nonlinear B.15 attempt failed acceptance

Milestone 5 implemented a source-faithful radial-inverse fixed-point
representation of Appendix B.15.

Tuple:

```text
aggressive pressure datum
Lambda = 512
g_peak = 0.1
sigma_star = 0.2
h = 0.005
j0 = 0.025
Y in [0,4.1]
eta in [-1,1]
```

No arbitrary boundary condition was imposed at `Y=4.1`.

The fixed-point increments became small, but independent original-equation
residuals did not converge under refinement.

The main cause was identified as severe underresolution of the narrow source

```text
G = g^2.
```

At 513 global Chebyshev eta nodes:

- source peak error was about 17%;
- interpolation developed negative lobes;
- derivative errors were large.

Therefore the apparently promising nonlinear correction from that iterate was
not accepted.

# 8. Narrow source scale

Near the negative root `eta0` of `H_star`, the local source behaves
approximately like a Gaussian.

For the fixed tuple:

```text
standard deviation of g    ~ 0.004169
standard deviation of g^2  ~ 0.002948
```

The central spacing of a 513-node Chebyshev-Lobatto grid is about:

```text
0.006136
```

so the `g^2` source is narrower than one local grid spacing.

This quantitatively explains the milestone-5 aliasing.

---

# 9. Sixth milestone resolved the source

Milestone 6 kept every model parameter unchanged and improved only the numerical
representation.

It introduced:

- matrix-free Chebyshev coefficient transforms;
- analytic derivatives of `G=g^2`;
- exact pressure factorization

\[
p(Y,\eta)=G(\eta)\,\bar P(Y,\eta),
\qquad
\bar P(Y,\eta)=\int_0^Y \Phi(s,\eta)^2\,ds.
\]

This avoids differentiating the narrow known source as a generic 2-D polynomial.

Source convergence:

```text
eta nodes   rel Linf G      rel Linf G_eta   rel Linf G_etaeta
513         1.71e-1         4.32e-1          2.24
1025        4.26e-3         2.11e-2          5.35e-1
2049        9.57e-9         9.57e-8          6.36e-6
```

Thus the source is now convincingly resolved at 2049 eta nodes.

Pressure factorization is also excellent:

```text
pressure residual       ~ 2.2e-14
Pbar_Y - Phi^2          ~ 3.5e-12
```

So the narrow-source problem has largely been removed.

# 10. New failure: endpoint instability

With the source resolved, the nonlinear fixed-point iteration still does not
produce an accepted solution.

At the best comparison-start snapshot:

```text
Angular residual:
global Linf             ~ 0.230
central-source Linf     ~ 1.6e-6

Axial residual:
global Linf             ~ 1.27e-3
central-source Linf     ~ 6.7e-9

Pressure residual       ~ 2.2e-14
```

The worst angular/axial residuals occur near:

```text
Y = 4.1
eta = -1
```

rather than near the narrow central source.

The iteration initially improves, then endpoint second-eta derivatives grow
dramatically.

Eventually the fixed-point map proposes negative `Phi`, so the run is rejected.

Both comparison and flat initial guesses show similar failure.

Current interpretation:

> The primary remaining obstacle is numerical endpoint instability, not source
> resolution.

Possible causes include:

- global Chebyshev endpoint differentiation amplification;
- roundoff amplification;
- loss of finite-parameter contraction of the fixed-point map;
- a mixture of these.

This has not yet been separated.

---

# 11. Sigma_star issue is independent

The current finite parameter

```text
sigma_star = 0.2
```

does not reproduce the paper's quantitative B.2 partition.

The sampled global maximum of

\[
\chi=\frac{H_*^2}{H_*^2+\sigma_*^2}
\]

is only approximately:

```text
0.988444
```

so no grid refinement can make this same sigma satisfy `chi > 0.99`.

A rootwise necessary estimate near one relevant zero suggests roughly:

```text
sigma_star < 0.00200285
```

for the `chi > 0.99` inequality there.

That is not a sufficient theorem condition.

Reducing sigma would also make the already narrow `g^2` source approximately
100 times narrower, so it should not be attempted until the numerical method
is much more robust.

# 12. How close are we to a physical approximation?

There are several distinct levels.

## A. Local explicit similarity comparison

Reached.

We can evaluate and validate the prescribed collapsing comparison field.

But this is not a nonlinear solved profile and not dynamic concentration.

## B. Local nonlinear B.15 core

Not yet reached, but plausibly close numerically.

The source is now resolved and pressure balance is essentially exact.

The remaining failure is localized to endpoint differentiation/iteration.

If an endpoint-stable eta representation produces convergent residuals and
derivatives at the same tuple, we would have a genuine finite nonlinear local
core approximation.

That would be an important milestone.

## C. Globally compatible finite mathematical construction

Not reached.

Missing or unverified:

- actual global moments;
- pressure-preserving angular correction realization;
- axial pulse realization;
- admissible Reynolds-stress structure;
- inner/exterior matching;
- later proof corrections.

The aggressive 8.78-decade model intentionally sacrificed some of these
supports.

## D. Dynamical Navier–Stokes concentration

Not attempted.

There has been no time integration showing a realizable initial state or
forcing evolving toward the core.

## E. Laboratory realization

Farther away.

Even the aggressive schedule spans about 8.78 decades in radius, and its
global matching/stress structure is incomplete.

A realistic experiment may eventually need to reproduce only the local
mechanism, not the full proof architecture.

# 13. Current scientific interpretation

The project has already learned several important things:

1. The literal theorem hierarchy is much too extreme to interpret directly as
   laboratory geometry.

2. The local pressure/core datum is surprisingly insensitive to enormous
   amounts of late proof geometry.

3. A heavily compressed exterior can reproduce the local datum to about
   `1e-11` while discarding many global proof supports.

4. The first finite nonlinear correction at `Lambda=512` is predicted to be
   modest.

5. The first nonlinear numerical failure was traced to a specific
   underresolved source, not to the mathematics.

6. After resolving that source, the remaining failure moved to an endpoint
   numerical instability.

This progression is encouraging because each failure has become more localized
and numerically interpretable.
